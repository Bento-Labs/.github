
# 🍱 Welcome to Bento

Bento offers liquid and non-custodial omni-chain savings products designed to provide low-risk, stable and diversified all-weather yields on USD stablecoins, ETH and BTC.

* **bentoX tokens** are fully backed by a diversified set of blue-chip X-denominated collateral assets generating yield via multiple strategies on top-rated DeFi platforms, delivering superior stable and convenient risk-adjusted yields.
* **Bento Savings Rate (BSR)** represents aggregated and optimized yield from diverse yield sources across DeFi, CeFi and TradFi.
* Bento pioneers truly **decentralized asset management** by distributing both $value and ownership to users. It allows users to choose either guaranteed native yield through Bento Savings Rate or speculative yield through BENTO governance token emissions.
